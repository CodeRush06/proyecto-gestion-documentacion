PROYECTO S.I.S.G.M


¿Qué es?


Este proyecto incluye dos módulos dirigidos a ayudar a la digitalización de sistemas hospitalarios, especialmente el Hospital de Clínicas que se ubica en Uruguay, Montevideo.
El primer módulo seria este, consiste en la digitalización de la documentación, generando un sistema de gestión de documentos digitales. Se plantea incluir QR para acceder a ellos.
Planeamos crear este módulo de la siguiente manera: La infraestructura de la aplicación serian 3 contenedores de Docker, 1 la aplicación (Incluyendo servidor Apache, sistema PHP para backend y JavaScript)
y los otros 2 contenedores serian para la base de datos(MariaDB) del hospital, 1 la base de datos en si y el otro contenedor seria un backup como respaldo de esta.


¿Para qué sirve?


Este modulo tiene el propósito de digitalizar documentación, solucionando un grave problema presente en los hospitales que es el uso de papel, remediando grandes perdidas económicas.
Dentro de un hospital, facilitará a los médicos y administradores a gestionar sus archivos, que pueden ser radiografias, etc.


¿Cómo se usa?


Esta planeado para ser usado mediante un navegador en un sitio web, y mediante ella los doctores o administradores podrán interactuar con la información presente en el sistema o publicar archivos propios.


¿Quiénes pueden contribuir con este Proyecto?


Este proyecto esta intencionado como proyecto de egreso de estudiantes de tercer año 2026, por ende solo los estudiantes del mismo equipo de proyecto (CodeRush) pueden contribuir al trabajo. 
Los docentes de la institución pueden contribuir mediante comentarios o sugerencias.



Manual de uso
Los administradores/Medicos acceden a Panel de administradores mediante su nombre y contraseña, al iniciar sesión  pueden visualizar los archivos ya publicados y publicar los suyos/crearlos. Por ahora solo se permiten estas dos funcionalidades.
